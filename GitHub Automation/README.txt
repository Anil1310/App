Welcome! This folder contains 1-click double-clickable macOS tools
to manage your GitHub repositories and deploy live to Netlify without
needing to memorize terminal commands.

HOW TO USE THESE TOOLS:

1. 🚀 1_Create_New_Repository.command
   - Double-click to create a brand new project.
   - Enter your project name (e.g., "my-portfolio" or "data-tool").
   - It creates the folder on your Desktop, initializes Git, creates the
     GitHub repository, pushes your code, and automatically DEPLOYS to Netlify!
   - Opens both your GitHub repository and live Netlify website in your browser!

2. ⚡ 2_Quick_Push_Changes.command
   - Double-click whenever you've made edits to your files.
   - Drag and drop your project folder into the terminal window and hit Enter.
   - Automatically commits, pushes to GitHub, and asks if you want to
     update the live site on Netlify!

3. 🌐 4_Deploy_To_Netlify.command
   - Double-click to deploy or re-deploy ANY web project straight to Netlify.
   - Drag and drop your project folder (or press ENTER for current project).
   - Generates the live URL (e.g., https://your-project.netlify.app)
     and automatically opens it in your default browser!

4. 📥 3_Clone_Repository.command
   - Double-click whenever you want to download an existing repository
     from your GitHub account straight to your Desktop.

NOTE: Uses your configured GitHub SSH key (Anil1310) for GitHub and
remembers your Netlify Token in ~/.automate-deploy.json so everything runs
completely hands-free!
